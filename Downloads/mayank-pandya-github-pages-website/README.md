# Dr. Mayank B Pandya — GitHub Pages Website

This is a static HTML/CSS/JavaScript website created from the supplied resume.

## Files

- `index.html` — website content
- `style.css` — responsive design
- `script.js` — mobile menu and current year
- `assets/profile.jpg` — profile image extracted from the supplied resume

## Publish with GitHub Pages (free)

1. Create/sign in to your GitHub account.
2. Create a new repository, for example `mayank-pandya-website`.
3. Upload **all files and folders** from this folder to the repository.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. GitHub will provide your public website address.

The site is completely static, so no database or backend server is required.

## Custom domain

Later, you can buy a domain such as `www.example.com` and connect it through the GitHub Pages custom-domain settings and your domain registrar's DNS settings.
